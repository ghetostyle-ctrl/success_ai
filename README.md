# 마브AI

경쟁 브랜드가 **지금 어떤 광고를 돌리고 있는지** 한 화면에서 훑어보는
레퍼런스 아카이브입니다. 브랜드명이나 도메인 하나만 넣으면 **구글 광고
투명성 센터**와 **메타 광고 라이브러리**에 공개된 그 브랜드의 광고를
모아서, 어떤 소재가 오래 살아남았고 어떤 게 지금 치고 올라오는지
보여줍니다.

무료입니다. 쓰는 데이터는 전부 각 플랫폼이 **공개해 둔 것**이고,
로그인이나 계정 연동이 없습니다. 수집한 데이터는 전부 내 PC의
SQLite 파일에 저장되고 어디로도 전송되지 않습니다.

---

## 1. 설치

**필요한 것**: Node.js 20 이상 ([nodejs.org](https://nodejs.org) 에서 설치)

```bash
git clone <이 저장소 주소>
cd mav-ai
npm install
```

## 2. 환경변수 만들기

`.env.local` 과 `.env` **두 개**를 만듭니다. 내용은 같습니다.

> 앱은 `.env.local` 을, Prisma CLI 는 `.env` 만 읽습니다.
> 하나만 만들면 `prisma db push` 가 실패합니다.

```bash
cp .env.example .env.local
cp .env.example .env
```

**Windows PowerShell** 이면:

```powershell
Copy-Item .env.example .env.local
Copy-Item .env.example .env
```

## 3. YouTube API 키 발급 (권장)

없어도 광고 수집은 되지만, **조회수·성과 배지(⭐주력 📈상승세 ⚡급등)가
전부 동작하지 않습니다.** 이 도구의 핵심 기능이라 꼭 받으시길 권합니다.
무료이고 5분이면 됩니다.

1. [Google Cloud Console](https://console.cloud.google.com) 접속 → 로그인
2. 상단에서 **새 프로젝트** 생성 (이름은 아무거나)
3. 좌측 메뉴 **API 및 서비스 → 라이브러리**
4. `YouTube Data API v3` 검색 → **사용 설정**
5. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
6. 만들어진 키를 복사해서 `.env.local` 의 `YOUTUBE_API_KEY=` 뒤에 붙여넣기

```
YOUTUBE_API_KEY=여기에_발급받은_키
```

> 🔒 발급 직후 **키 제한**을 걸어두세요. 키 옆 ✏️ → *API 제한사항* →
> `YouTube Data API v3` 만 선택. 키가 새어나가도 피해가 없습니다.
>
> 하루 할당량은 10,000 유닛(무료)입니다. 영상 1개 조회에 1 유닛이라
> 보통 넉넉하지만, 대형 광고주를 여러 번 돌리면 닿을 수 있습니다.
> 수집이 조용히 멈추면 할당량 초과부터 의심하세요.

## 4. 실행

```bash
npx prisma generate   # DB 클라이언트 생성
npx prisma db push    # 빈 DB 파일 만들기
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다.

> 다음부터는 `npm run dev` 만 실행하면 됩니다.

## 사용법

### 브랜드 불러오기

상단 검색창에 **브랜드명**(`올리브영`) 또는 **도메인**(`oliveyoung.co.kr`)을
넣고 **불러오기**를 누릅니다. 30~90초쯤 걸립니다.

- 쉼표로 여러 개를 한 번에 넣을 수 있습니다
- **📸 1회만** 을 켜면 이번 조사만 하고 자동 갱신 대상에서 빠집니다
- 도메인으로 넣으면 그 도메인이 직접 띄운 광고를, 브랜드명으로 넣으면
  광고주 단위로 찾습니다

### 화면 다섯 개

| 탭 | 하는 일 |
|---|---|
| 🗂 **브랜드 아카이브** | 첫 화면. 브랜드마다 카드 하나, 안에 최근 소재 썸네일 |
| 📋 **광고 목록** | 표로 파고들기. 정렬·필터·CSV/JSON·소재 mp4 다운로드(⬇) |
| 🎬 **소재 비교** | 브랜드를 가로질러 영상 광고만 모아 비교 |
| 📊 **대시보드** | 추적 중인 브랜드 전체 현황 |
| 📘 **메타 광고** | 메타 광고 라이브러리 수집·조회 |

### 소재에 붙는 배지

**같은 브랜드를 며칠에 걸쳐 다시 불러오면** 일별 조회수가 쌓이고, 그
추이로 배지가 자동으로 붙습니다.

| 배지 | 기준 |
|---|---|
| ⭐ 주력 | 누적 50만+ 이면서 하루 평균 5천+ |
| 📈 상승세 | 최근 3일 평균 증가량이 전체 평균의 1.25배 이상 |
| ⚡ 급등 | 직전 대비 180% 이상 폭증 |
| 📉 둔화 | 최근 3일 연속 증가량 하락 |
| 🌱 새 캠페인 | 투명성 센터에 처음 잡힌 지 10일 이내 |
| 🎞 새 소재 | YouTube 게시 21일 이내 |

⭐ 📈 ⚡ 📉 는 스냅샷이 2~3개 쌓여야 붙습니다. **첫날에는 안 보이는 게
정상입니다.** 며칠 돌려야 의미가 생깁니다.

### 소재 다운로드 (선택)

광고 목록 탭에서 `보기` 옆 **⬇** 를 누르면 그 영상을 mp4 로 받습니다.
`yt-dlp` 가 필요합니다.

```bash
winget install yt-dlp.yt-dlp    # Windows
brew install yt-dlp ffmpeg      # macOS
```

설치 후 **앱을 재시작**해야 인식됩니다.

## 자주 겪는 문제

**수집이 실패하고 `/sorry/` 나 `bot challenge` 가 뜹니다**
구글이 봇으로 보고 막은 겁니다. 한꺼번에 많이 긁으면 걸립니다.
**1~3시간 기다렸다가** 다시 하세요. 자주 겪는다면 `.env.local` 의
`PROXY_URL` 에 주거용 프록시를 넣으면 거의 사라집니다.

**`prisma db push` 가 `datasource.url property is required` 로 실패합니다**
`.env` 파일이 없습니다. 위 2번에서 `.env` 도 만들었는지 확인하세요.

**조회수가 전부 비어 있고 배지가 안 붙습니다**
`YOUTUBE_API_KEY` 가 없거나 할당량을 초과했습니다. 위 3번을 확인하세요.

**⬇ 를 눌러도 "yt-dlp 가 설치돼 있지 않습니다" 가 뜹니다**
위 *소재 다운로드* 항목대로 설치하고 앱을 재시작하세요.
